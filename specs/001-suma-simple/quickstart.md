# Quickstart: Suma simple

## Prerequisites

- Node.js 22+ (matches Docker base image)
- npm
- Docker (optional, for container run)

## Install

```bash
npm install
```

## Build

```bash
npm run build
```

## Test

```bash
npm test
```

## Lint

```bash
npm run lint
```

## Run locally

```bash
npm run dev
```

Then open http://localhost:5173

## Run with Docker

```bash
docker compose up --build
```

Then open http://localhost:5173

## Deploy

- Vercel deploys a static site using `vercel.json`.
- Use the Vercel dashboard or GitHub integration to deploy the repository.
